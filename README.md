# YAML Learning

## What is YAML?

YAML (YAML Ain't Markup Language) is a human-readable data-serialization language. It is often used for configuration files, but it can also be used for data exchange between languages.

## Why use YAML?

- **Human-readable**: YAML is designed to be easy to read and write.
- **Data-oriented**: YAML is designed to store and exchange data.
- **Cross-language**: YAML can be used with many different programming languages.

## YAML vs JSON

| Feature | YAML | JSON |
|---------|------|------|
| Readability | High | Medium |
| Comments | Yes | No |
| Data types | Rich | Limited |
| Syntax | Flexible | Strict |

## Examples

### Basic Syntax

```yaml
name: John Doe
age: 30
isStudent: false
```

### Lists

```yaml
hobbies:
  - reading
  - hiking
  - coding
```

### Dictionaries

```yaml
address:
  street: 123 Main St
  city: Anytown
  state: CA
  zip: 12345
```

### Nested Data

```yaml
person:
  name: Jane Doe
  age: 25
  address:
    street: 456 Elm St
    city: Anytown
    state: CA
    zip: 12345
```
